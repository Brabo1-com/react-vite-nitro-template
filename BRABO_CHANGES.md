## Functional preparation

Frontend routing, all UI components, Nitro backend and the component-selection protocol are retained. The local tagger carries the exact original 0.9.0 runtime bytes/LICENSE with renamed private metadata and lib paths, without an npm account or external Dyad dependency. Identifiers data-dyad-* remain compatibility attributes. Brabo identity and own MIT SVG favicon replace product branding; the uninspected original binary favicon was not copied. Placeholder SVG matches the licensed scaffold.

The canonical pnpm 10.11.0 lock includes Nitro 3.0.260429-beta and required jiti 2.6.1. The inconsistent reference npm lock is omitted. h3 2.0.1-rc.22 and ocache 0.1.4 are preserved from its npm lock through explicit Nitro dependency overrides; newer fresh h3 resolution requested incompatible ocache. React Router follows the licensed scaffold range ^6.30.4. Existing React 19 versus legacy Radix/vaul peer warnings remain; no broad UI dependency migration is claimed.

Node start script and backend/config type checking added. Two empty UI interfaces became equivalent aliases; Tailwind plugin import became ESM for lint. Generated/vendor output is excluded from lint and Git; existing component Fast Refresh warnings remain. No functionality was disabled to make checks pass.

The SPA-only Vercel catch-all rewrite was replaced by Brabo provider metadata so Nitro emits server-aware output. Local vercel preset build emitted Build Output API v3 and the API handler; external deployment remains unverified. Default Node output was restored and the API/frontend tests repeated.
